# Smart Grid Stability Predictor

A Streamlit application for predicting smart-grid stability with MLP and XGBoost models, with SHAP and LIME explanations.

## Run in VS Code

Press **Ctrl+Shift+B** to train both models and start the Streamlit app, then open http://127.0.0.1:8502.

## Train from the terminal

```powershell
python run_training.py
```

## Dependencies

Install packages listed in `requirements.txt` in your Python environment.
